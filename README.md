# dotfiles
My dotfiles for Arch Linux systems

## Requirements
| Package  | Version |
| -------- | ------- |
| Niri     | Last    |
| Noctalia | v5      |
| -------- | ------- |

## Command to install everything and apply all configs (bash script)

```bash
git clone https://github.com/deltashrimp/dotfiles.git && cd dotfiles && ./install.sh
```
